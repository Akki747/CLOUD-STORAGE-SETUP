Cloud Storage Setup Using AWS S3
Project Description

I have implemented a cloud storage system using Amazon Web Services (AWS) S3 (Simple Storage Service). The main purpose of this project is to understand how cloud storage works in real-world applications and how data can be stored, managed, and accessed securely over the internet.

AWS S3 is a widely used cloud storage service that allows users to store files such as documents, images, videos, and application data in a scalable and secure way. In this project, I practiced basic cloud operations like bucket creation, file uploading, and setting access permissions.

What I Have Done
1. Created AWS S3 Bucket

I have logged into the AWS Management Console and created an S3 bucket. While creating the bucket, I provided a unique name and selected an appropriate region. After successful creation, the bucket appeared in the S3 dashboard and was ready for use.

This step helped me understand how cloud storage containers (buckets) are created and managed in AWS.

2. Uploaded Files into the Bucket

After creating the bucket, I have uploaded five sample files into it. These files were used to test how data is stored in cloud storage. The upload process was done using the AWS S3 interface, and after uploading, I verified that all files were successfully stored in the bucket.

This helped me understand how objects (files) are stored inside a cloud bucket.

3. Configured Access Permissions

I have configured access permissions using AWS IAM (Identity and Access Management) and bucket policies. I controlled the access level of the files by setting proper permissions for reading and writing data.

This step ensured that only authorized users can access or modify the data stored in the bucket, improving security in the cloud environment.

4. Verified File Access

I have tested the uploaded files using the AWS console. I checked whether the files are accessible based on the permissions set. I confirmed that all files were properly uploaded and could be accessed securely.

This helped me understand how verification works in cloud storage systems.

Deliverables
Successfully created AWS S3 bucket
Uploaded five sample files into the bucket
Configured access permissions using IAM policies
Verified file storage and access functionality
Understood basic cloud storage workflow
Security Implementation

In this project, I learned how security plays an important role in cloud computing. I configured access control using AWS IAM policies to ensure data protection. I understood how permissions can be managed to allow or restrict access to cloud resources.

Learning Experience

Through this project, I gained practical knowledge of:

Cloud computing fundamentals
AWS S3 bucket creation and management
File upload and storage in cloud environment
Access control and permission management
Real-time cloud storage operations

This hands-on experience helped me understand how companies store and manage large amounts of data using cloud platforms.

Real-World Importance

Cloud storage is widely used in industries for data backup, file sharing, application storage, and big data processing. Services like AWS S3 provide high availability, scalability, and security, making them essential in modern software systems.

Conclusion

I have successfully completed the cloud storage setup using AWS S3. I created a bucket, uploaded files, and configured permissions. This project helped me gain practical exposure to cloud computing and understand how data is stored and managed securely in the cloud.
